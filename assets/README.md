# Brand assets

| File | Use |
|---|---|
| `icon.svg` | app / package icon, 256 viewBox |
| `favicon.svg` | 32px tab mark |
| `wordmark.svg` | README / docs header |

Palette: `#0B1220` ground, `#2EE6C5` orbit, `#F5B942` completion tick, `#F4EFE6` π.

The mark is an open orbit around π: the job leaves, the tick is the harvest handoff. Do not add scheduler vendor logos.
